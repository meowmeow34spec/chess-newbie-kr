# 체스 왕초보 가이드

완전 초보를 위한 첫 오프닝 세 개(백: 이탈리안 게임, 흑 1.e4 상대: 카로칸 디펜스, 흑 1.d4 상대: 퀸즈 갬빗 거절)와 하루 30분 4주 플랜을 한 페이지로 정리했어요.

- `index.html`: 페이지 전체 (CSS·JS·폰트 내장, 외부 요청 없음)
- `assets/video/`: 오프닝 수순 영상 3개 (MP4)
- `assets/img/`: 영상 포스터 이미지

압축을 풀고 `index.html`을 브라우저로 열면 돼요. 인터넷 연결이 없어도 동작해요.
내용 출처: 체스 입문 정리 (그록헤비 3회 조사, 2026-10-19)
