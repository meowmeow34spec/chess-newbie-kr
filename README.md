# 체스 왕초보 가이드

완전 초보를 위한 첫 오프닝 두 개(백: 이탈리안 게임, 흑: 카로칸 디펜스)와 하루 30분 4주 플랜을 한 페이지로 정리했어요.

- `index.html`: 페이지 전체 (CSS·JS·폰트 내장, 외부 요청 없음)
- `assets/video/`: 오프닝 수순 영상 2개 (MP4)
- `assets/img/`: 영상 포스터 이미지

브라우저에서 `index.html`을 바로 열거나, GitHub Pages(브랜치 루트)로 배포하면 돼요.
